3lb Combat Robot: Baba Yaga

Current Iteration: Version 4 (In development)

Project Overview

Baba Yaga is a 3lb beetleweight combat robot designed for high-energy structural engagements. The project is focused on maximizing power-to-weight efficiency while isolating sensitive radio and speed control components from hard kinetic shock impacts.

Version 3 (Completed)

Version 3 proved out the core electronic components and drive speed. (Photos and build breakdown to be embedded here soon).

Version 4 (Active Build)

Currently in production. Upgrades focus on improving main drive assembly durability and rewriting custom receiver code profiles for snappier drift compensation.
